## 🛠 How I work

**Product** → expected behavior, business rules and scope

**Engineering** → feasibility, architecture and implementation constraints

**AI** → ambiguity discovery, specification and work decomposition

I use AI to make decisions, contracts and handoffs more explicit — not to replace Product or Engineering judgment.
